# Changelog

## 0.1.0 - 2026-10-09

- Causal features: rolling median and MAD, EWMA, first difference, rolling std.
- Three detectors: robust Z-score, sudden-change test, Isolation Forest.
- 2-of-3 vote and a five-state mitigation state machine.
- Synthetic utility stream with spike, level-shift and flood attacks.
- `edgeguard demo` and `edgeguard run` commands.
- 27 tests, CI on Python 3.10-3.12, release workflow on version tags.
